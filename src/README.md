# src

## Overview
Standalone iOS Scriptable widget scripts and reusable CommonJS carrier modules for Mi Telcel (`MiTelcelWidget.js`), Mi Bait (`MiBaitWidget.js`), Mi Movistar (`MiMovistarWidget.js`), and Mi AT&T (`MiATTWidget.js`), plus the interactive Keychain credential reset script (`ResetearPassword.js`). Part of the root technical blueprint ([`../README_TECH.md`](../README_TECH.md)).

## Interface
- `MiTelcelWidgetv2.js`: versión autónoma para Scriptable con OIDC directo, una sesión por consulta, validación inicial reutilizando el consumo obtenido y revocación en `finally`. Expone `module.exports` para sus pruebas, con `main`, `CONFIG`, `TelcelError`, `loadState`, `saveState`, `assertCanAttempt`, `configureCredentials`, `requestText`, `loginTelcelSSO`, `extractMtlBasic` y `fetchDynamicMtlBasic`. Desde 2.0.3 usa `await main()` en el nivel superior: las pruebas la cargan con `AsyncFunction` para reproducir el contexto de Scriptable; no se carga con `require()` nativo de Node. El cliente Android sigue usando el módulo CommonJS original.
- `MiTelcelWidgetv2.js:readCredentialForm` / `credentialFormHTML` / `withFormTimeout`: captura en un WebView local con CSP sin conexiones, sin depender de `Alert.textFieldValue`. Desde 2.0.3, `shouldAllowRequest` se instala después de cargar el HTML y permite `about:blank` para no bloquear la navegación local. Carga/lectura tienen límite de 10 segundos, limpieza de 2 segundos y presentación interactiva sin límite. El usuario toca Continuar y cierra con Listo. Los valores solo se conservan en memoria, se consumen una vez y la página se limpia en `finally`. Cerrar o cancelar no autentica. Las pruebas ejecutan el manejador del HTML y el archivo completo, incluyendo carga diferida, política de navegación y temporizador nativo simulado; el formulario HTML también se verificó en navegador.
- `[src/MiTelcelWidget.js:module.exports]` `{ fetchTelcelData, parseTelcelResponse, createWidget, loadCache, getCredentials, validateTelcelCredentials, requestTelcel }`
- `[src/MiBaitWidget.js:module.exports]` `{ fetchBaitData, parseBaitResponse, createWidget, loadCache, fetchServiceKey, CONFIG, getCredentials, validateBaitCredentials, requestBait, requestText }`
- `[src/MiMovistarWidget.js:module.exports]` `{ fetchMovistarData, parseMovistarResponse, decryptMovistarContent, extractGuardKey, fetchGuardKey, getGuardKey, createWidget, loadCache, validateMovistarCredentials, validateMovistarSession, loginWithWebView, getSessionToken, getCredentials, requestMovistar }`
- `[src/MiATTWidget.js:module.exports]` `{ fetchATTData, parseATTResponse, aesEncrypt, aesDecrypt, evpBytesToKey, md5, extractSessionKey, createWidget, loadCache, validateATTCredentials, getCredentials, requestATT, CONFIG }`
- `[src/ResetearPassword.js:KEYCHAIN_KEYS]` Top-level mapping of carrier display names to Keychain keys (`Mi Telcel`: `["TELCEL_PASS", "TELCEL_PHONE"]`, `Mi Bait`: `["BAIT_PHONE"]`, `Mi Movistar`: `["MOVISTAR_PID", "MOVISTAR_GUARD_KEY"]`, `Mi AT&T`: `["ATT_PASS", "ATT_PHONE"]`).

## Invariants
- `MiTelcelWidgetv2.js`: persiste una pausa preventiva antes de enviar credenciales, limita el intervalo a un mínimo de 15 minutos (60 predeterminado), pausa ante fallos de SSO/rechazo HTTP o cierre no confirmado y exige revisión manual tras al menos 30 minutos. La primera configuración pide credenciales actuales aunque existan las llaves anteriores. No alterna métodos de login automáticamente ni fabrica un HTTP 401 si falta el código OIDC. El estado ilegible falla cerrado. La fecha `updatedAtISO` conserva la antigüedad real de la caché; `cutoffISO` permite recalcular días restantes.
- `MiTelcelWidgetv2.js:createWidget`: desde 2.0.4 reserva ancho para marca y días, centra el gauge con espaciadores y usa columnas de 58 puntos con tipografía idéntica para ambas estadísticas. El gauge de 320×160 se presenta a 120×60 sin deformar su proporción. El pie de una línea usa símbolos con presentación de texto, muestra edad de caché a partir de una hora y resalta datos antiguos/pausas. No divide el renderizado en helpers ni modifica el flujo de autenticación. La vista previa HTML usada para revisar tamaños es una aproximación del layout de Scriptable, no una captura del dispositivo.
- Desde 2.0.6, la píldora de días usa un `DrawContext` de 156×78 presentado a 52×26 puntos: etiqueta y valor se dibujan juntos para evitar la compresión del texto observada en stacks nativos anidados. Mantiene singular/plural y el semáforo de corte.
- `MiTelcelWidgetv2.js:usageAlertRisk` / `notifyUsageRisk` / `sendTestUsageNotification`: desde 2.1.0, evalúa los umbrales 80%/7 días, 90%/3 días y 95%/2 días después de preparar el widget con consumo fresco. No realiza peticiones de red ni avisa con caché, datos de más de 15 minutos o `daysLeftEstimated`. El historial independiente `mitelcel_v2_alerts.json` limita un aviso por nivel/ciclo, 24 h entre avisos y una hora entre intentos fallidos; guarda hasta seis ciclos y tolera un día de variación del corte. Reserva nivel/hora antes de programar para evitar duplicados si iOS interrumpe la ejecución. Un error confirmado revierte la reserva de envío conservando la hora del intento. Fallos de permisos o historial se capturan sin modificar la protección SSO. La prueba manual utiliza un identificador independiente y no consume los avisos del ciclo. El historial se reinicia tras validar un cambio de línea, sin nuevas llaves de Keychain.
- `[src/MiTelcelWidget.js:validateTelcelCredentials]` / `[src/MiTelcelWidget.js:fetchTelcelData]` Authenticate via `loginTelcelSSO` with automatic fallback from WebLogin 8443 to OIDC (`https://www.mitelcel.com/oid-authorize-prod`) when F5 Bot Defense rejects requests or returns empty bodies; intercept redirects and preserve upstream status errors; always revoke `ssoToken` via `POST https://dev.smapps.mx:9000/sso/revoke` inside a `finally` block whenever a token is acquired.
- `[src/MiTelcelWidget.js:getCredentials]` / `[src/MiBaitWidget.js:getCredentials]` / `[src/MiATTWidget.js:getCredentials]` / `[src/MiMovistarWidget.js:loginWithWebView]` Normalize phone numbers to the last 10 digits, reject placeholder `'5512345678'` and `'TU_PASSWORD'`, and persist credentials/tokens to iOS `Keychain` only after live upstream validation succeeds.
- `[src/MiTelcelWidget.js:parseTelcelResponse]` / `[src/MiTelcelWidget.js:createWidget]` Use `1 GB = 1000 MB` for Telcel commercial labels and `1 MB = 1024 KB` for fallback chart data; discover and numerically sort `tabs-plans-v2-plan-name-(\d+-\d+-\d+)` suffixes (preferring non-`web-`), identify base buckets via `/^(web-)?0-0-0$/`, filter zero-available promotional buckets ONLY when multiple promotional buckets exist and at least one has active data (`hasActivePromo`) to eliminate obsolete plan-change buckets while preserving legitimately exhausted promotions and 100% consumed plans, discard empty buckets (`totalMB <= 0 && availableMB <= 0`), default `daysLeft` to `28`, and throw if no active buckets remain.
- `[src/MiBaitWidget.js:parseBaitResponse]` / `[src/MiBaitWidget.js:createWidget]` Use `1 GB = 1024 MB`; require `payload.success && Array.isArray(payload.data)`; sum only `BestEffort`, `Throttling`, and non-expired `Benefits.offers_detail[]` (`exp >= today`) where `totalMB > 0 || availableMB > 0`; throw if no active data buckets exist.
- `[src/MiMovistarWidget.js:decryptMovistarContent]` / `[src/MiMovistarWidget.js:parseMovistarResponse]` Require `<base64url_cipher>:<base64url_12B_iv>` format and 32-char `guardKey` for AES-256-GCM decryption (retrying once with freshly fetched `guardKey` on rotation); require non-empty `bolton` array, skip social/voice/SMS boltons, convert with binary `1024` factors, and throw if neither data buckets nor an unlimited data bolton exist.
- `[src/MiATTWidget.js:evpBytesToKey]` / `[src/MiATTWidget.js:aesEncrypt]` / `[src/MiATTWidget.js:aesDecrypt]` / `[src/MiATTWidget.js:parseATTResponse]` Derive 32-byte key + 16-byte IV via 3-round MD5 over password + 8-byte salt with `Salted__` header (`SALTED_MAGIC`, verified in constant time on decrypt); filter allowances to byte-based `UnitType`, exclude social/streaming/voice/SMS and expired items (`endDt < today`), convert with binary `1024` factors, treat `Unlimited === "Y"` or `total >= 99999000` MB as unlimited, and throw if no active data buckets or unlimited flag exist.
- `[src/MiBaitWidget.js:loadCache]` / `[src/MiMovistarWidget.js:loadCache]` / `[src/MiATTWidget.js:loadCache]` Recalculate `daysLeft` dynamically from persisted `cutoffISO` (`YYYY-MM-DD`) against the current date and set `fromCache = true`.
- `[src/MiTelcelWidget.js:drawSemicircleGauge]` / `[src/MiBaitWidget.js:drawSemicircleGauge]` / `[src/MiMovistarWidget.js:drawSemicircleGauge]` / `[src/MiATTWidget.js:drawSemicircleGauge]` Clamp `spentRatio` to `[0, 1]`, apply a `0.11` rad gap when `0.04 < clamped < 0.96`, draw only the gray track (`#2C2C2E`) when `spentRatio` is null/non-finite (`totalMB <= 0`), and set error widget URL to `scriptable:///run?scriptName=...` when `!data`.

## Side Effects
- `MiTelcelWidgetv2.js`: utiliza las mismas llaves `TELCEL_PHONE` y `TELCEL_PASS` (sin nuevas llaves que añadir a `ResetearPassword.js`) y archivos locales independientes `mitelcel_v2_usage_cache.json`, `mitelcel_v2_state.json` y `mitelcel_v2_public_basic.json`. Este último solo contiene la clave pública de la aplicación web; ninguno guarda tokens SSO/B2F o credenciales. Muestra el nombre de versión y la antigüedad de los datos; tocarlo abre Scriptable. `tests/test_telcel_v2.mjs` se integra en `node tests/test_parser.mjs`.
- `[src/MiTelcelWidget.js:getCredentials]` / `[src/MiBaitWidget.js:getCredentials]` / `[src/MiMovistarWidget.js:loginWithWebView]` / `[src/MiATTWidget.js:getCredentials]` / `[src/ResetearPassword.js:picker]` Read, write, and delete keys in iOS `Keychain` (`TELCEL_PHONE`, `TELCEL_PASS`, `BAIT_PHONE`, `MOVISTAR_PID`, `MOVISTAR_GUARD_KEY`, `ATT_PHONE`, `ATT_PASS`) and present interactive Scriptable `Alert` / `WebView` UI when not running inside a widget.
- `[src/MiTelcelWidget.js:fetchTelcelData]` / `[src/MiBaitWidget.js:fetchBaitData]` / `[src/MiMovistarWidget.js:fetchMovistarData]` / `[src/MiATTWidget.js:fetchATTData]` Perform live HTTP requests to carrier endpoints (`wbl.telcel-id.com:8443`, `www.mitelcel.com/oid-authorize-prod`, `mi-telcel.smapps.mx`, `api.journeys.telcel.wavebybemobi.com`, `dev.smapps.mx:9000`, `mibait.com`, `mi.movistar.com.mx`, `miattweb.att.com.mx`).
- `[src/MiTelcelWidget.js:saveCache]` / `[src/MiBaitWidget.js:saveCache]` / `[src/MiMovistarWidget.js:saveCache]` / `[src/MiATTWidget.js:saveCache]` Read and write JSON cache files (`mitelcel_usage_cache.json`, `mibait_usage_cache.json`, `mimovistar_usage_cache.json`, `miatt_usage_cache.json`) in `FileManager.local().documentsDirectory()`.
- `[src/MiTelcelWidget.js:main]` / `[src/MiBaitWidget.js:main]` / `[src/MiMovistarWidget.js:main]` / `[src/MiATTWidget.js:main]` Auto-execute at top level when `typeof Script !== "undefined"`, binding widget output via `Script.setWidget(widget)` or presenting preview via `widget.presentSmall()`, and calling `Script.complete()`.
